## 三、問題回答

### 問題一：為什麼 `"4"` 要先轉成數字，才能用於本題的分攤計算？

在 Python 中，`"4"` 是字串（`str`）型別，代表文字字元而不是數值。若直接拿字串進行除法運算（例如 `1220 / "4"`）會發生 `TypeError` 錯誤，也無法進行數值大小比較；必須透過 `int("4")` 轉成整數 `4`，才能正確計算每人分攤的金額。

### 問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？

若先扣折價券再算服務費，第一組的計算會變成：
- 扣折價券後餐費：`1200 - 100 = 1100` 元
- 服務費：`1100 * 0.10 = 110` 元
- 應付總額：`1100 + 110 = 1210.00` 元

這與題目規定的 `1220.00` 元不同，原因是**服務費計算的基準不同**：題目規定服務費必須以「原始餐費（1,200 元）」計算（`1200 * 0.10 = 120` 元，總額 `1200 + 120 - 100 = 1220` 元），而先扣折價券會讓服務費少算了 `100 * 0.10 = 10` 元，導致總額少了 10 元。
